How people learn to work with algorithms

BOBALAB is a research lab at UC Berkeley’s Haas School of Business, led by Prof. Park Sinchaisri.

Algorithms now assign gig work, give advice and help teachers plan lessons. Using field data and experiments, we study how people learn and decide alongside them, so that work with AI goes better for people.
