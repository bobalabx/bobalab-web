# WP6 request 1: git-ignore the generated local CMS pages

- File(s): `.gitignore` (WP0)
- Why: the local no-account demo (brief §F4; `npm run cms:local`, `tests/e2e/cms-local.spec.ts`) generates files next to the production admin page. `config.local.yml` is already ignored; its companion page `local.html` is not, and neither is `_csp-probe.html`, a copy of `local.html` without `'unsafe-eval'` that the e2e spec writes for a few seconds to measure the CSP. Both pages carry a CSP that allows the local proxy (`connect-src http://localhost:8081`), which must never reach production. They are removed again when `cms:local` exits and after the e2e run (also on failure), but an interrupted run could leave them behind for a commit.
- Proposed change: next to the existing line, add two lines:
  ```diff
   # Decap local proxy config (generated by scripts/cms; WP6)
   /public/admin/config.local.yml
  +/public/admin/local.html
  +/public/admin/_csp-probe.html
  ```
- Blocking? no (the files are cleaned up automatically; the integrator should not commit `public/admin/local.html` or `public/admin/_csp-probe.html` if either is ever present).
- Test that proves it: `node scripts/cms/build-config.mjs --local && git status --short public/admin` shows nothing new; `node scripts/cms/build-config.mjs --clean-local` removes both local files.
- Review note (2026-10-20, WP6 adversarial review): confirmed neither file is present after the e2e run; `_csp-probe.html` added to the request.

Status: Applied in integration commit "integration: apply change requests" (2026-10-20).
